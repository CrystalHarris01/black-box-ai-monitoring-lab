What This Project Does

Output Monitoring

Scans AI-generated responses for risky patterns, blocked topics, and sensitive data indicators before treating the output as trustworthy.

Risk Scoring

Translates findings into severity levels so reviewers can quickly understand whether the response is low, medium, high, or critical risk.

Audit Evidence

Records prompt-response activity, findings, timestamps, and status results to support traceability and governance review.

Governance Alignment

Connects technical controls to AI governance concepts including ISO/IEC 42001, ITIL AI, ETTC, monitoring, and accountability.

System Flow

  1. User submits a prompt through the Streamlit interface.
  2. The app sends the prompt to an LLM through an API.
  3. The response is scanned by custom monitoring logic.
  4. Findings are converted into a risk score and severity level.
  5. The interaction is written to an audit log for governance evidence.

Why It Matters

This project is meant to show more than a chatbot. It demonstrates the monitoring layer organizations need when deploying AI into real operational environments. The lab focuses on practical AI assurance: policy enforcement, auditability, risk scoring, and governance visibility.
